# Evidence on LLM-driven trading decisions vs mechanical rules (2023–2026)

Scope note: almost all rigorous evidence is for **daily** (or at best hourly) decisions on stocks/crypto. I found **no peer-reviewed study that evaluates an LLM choosing direction minute-by-minute from OHLC bars + EMAs/ATR**. The closest things to the user's setup are (a) the AI-Trader benchmark (hourly NASDAQ-100, Oct–Nov 2025), (b) the nof1 Alpha Arena live crypto contest (3-minute decision cadence, perps, real money) and its independent statistical critique, and (c) one GitHub hobby bot (kojott) that moved from 3-minute to 15-minute bars. Source quality is flagged inline: [peer-reviewed/venue], [arXiv preprint], [live contest], [anecdote].

## KQ1. Which papers evaluate LLMs on trading/forecasting from price data, and what did they find about edge (short horizon vs daily)?

### Takeaway
Across the 2025 live/uncontaminated benchmarks (StockBench, AI-Trader, LiveTradeBench, Agent Market Arena) most frontier LLM agents fail to beat passive buy-and-hold on a risk-adjusted basis, dispersion between models is large and unstable, and the only setting where LLMs show a robust, replicated edge is **news/headline sentiment at the daily horizon** (Lopez-Lira & Tang), not reading price bars. No rigorous study shows edge from LLMs reading OHLC/indicators at intraday horizons; the one hourly benchmark (AI-Trader) shows 2 of 6 models beating QQQ over a 5-week window with much higher volatility and drawdown.

### Cited Findings

**Daily-horizon, price-plus-news agent benchmarks (arXiv preprints, 2025)**
- StockBench (arXiv 2510.02209, Oct 2025): 20 DJIA stocks, 82 trading days (Mar 3–Jun 30 2025), daily decisions at open, $100k, JSON output, 3 seeds averaged. Final returns: Kimi-K2 1.9%, Qwen3-235B-Think 2.5%, Claude-4-Sonnet 2.2%, GPT-5 0.3%, DeepSeek-V3.1 1.1%, GPT-OSS-20B −2.8%; passive buy-and-hold 0.4% with −15.2% MDD. Sortino values are all tiny (0.013–0.042 vs 0.0155 baseline). The abstract says "most LLM agents struggle to outperform the simple buy-and-hold baseline", while Table 2 shows 8/14 above the 0.4% baseline return — the paper's own framing is inconsistent. — [StockBench HTML](https://arxiv.org/html/2510.02209v1); [abstract](https://arxiv.org/abs/2510.02209v1)
- StockBench regime split: in the downturn window (Jan–Apr 2025) **no** LLM agent beat the passive baseline; in the upturn window (May–Aug 2025) most did. — [StockBench HTML](https://arxiv.org/html/2510.02209v1)
- StockBench ablation (Kimi-K2): full input 1.9% → without news 1.4% → without news and fundamentals 0.6%; i.e. most of the (small) edge came from news, not from prices. — [StockBench HTML](https://arxiv.org/html/2510.02209v1)
- AI-Trader (arXiv 2512.10971, Dec 2025, HKUDS): live, data-uncontaminated benchmark. **U.S. NASDAQ-100 at hourly granularity** (Oct 1–Nov 7 2025), A-shares daily, crypto daily. Six LLMs: DeepSeek-v3.1, MiniMax-M2, Claude-3.7-Sonnet, GPT-5, Qwen3-Max, Gemini-2.5-Flash. Minute-level trading is not tested. — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- AI-Trader hourly U.S. results (CR / Sortino / Vol / MDD): MiniMax-M2 9.56% / 4.42 / 25.4% / −4.92%; DeepSeek-v3.1 8.39% / 3.73 / 26.0% / −8.58%; Claude-3.7-Sonnet 3.11% / 1.13 / 21.8% / −8.13%; GPT-5 1.56% / 0.70 / 28.6% / −10.55%; Qwen3-Max 0.39%; Gemini-2.5-Flash −0.06%; **QQQ baseline 1.87% / 1.51 / 17.2% / −3.94%**. So 2 of 6 beat the index on return but all ran 25–33% vol vs 17% and 2–3× the drawdown. — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- AI-Trader A-shares (daily): no model beat SSE-50 on return (best MiniMax 1.31% vs 1.65%); crypto (daily, Nov 1–14 2025): all six lost 12–19%, only DeepSeek (−12.18%) beat the CD5 index (−14.30%). Authors' summary: "general intelligence doesn't automatically translate into trading ability", "most agents earned poor returns and showed weak risk management", "risk control appears to determine robustness". — [AI-Trader abstract](https://arxiv.org/abs/2512.10971); [HTML](https://arxiv.org/html/2512.10971v1)
- LiveTradeBench (arXiv 2511.03628, Nov 2025, UIUC): 50-day live evaluation of 21 LLMs on U.S. stocks and Polymarket; agent sees prices, news, portfolio and outputs percentage allocations. Findings: "strong scores on LMArena do not imply better trading outcomes"; models show distinct portfolio styles tied to risk appetite. No baseline numbers on the abstract page. — [LiveTradeBench](https://www.arxiv.org/abs/2511.03628); [code](https://github.com/ulab-uiuc/live-trade-bench)
- Agent Market Arena / "When Agents Trade" (arXiv 2510.11695, Oct 2025): four agent frameworks (InvestorAgent, TradeAgent, HedgeFundAgent, DeepFundAgent) × five backbones (GPT-4o, GPT-4.1, Claude-3.5-haiku, Claude-sonnet-4, Gemini-2.0-flash) on live crypto and stocks. Main finding: the **agent framework/structure** drove behavior (aggressive vs conservative) far more than the choice of LLM backbone. — [AMA abstract](https://arxiv.org/abs/2510.11695)
- TradingAgents (arXiv 2412.20138): multi-agent debate framework; reports Sharpe "surpassing all baseline models" but the authors themselves say the highest Sharpe "exceeds our expected empirical range" and the backtest covers only ~3 months on AAPL/GOOGL/AMZN because each decision needs many LLM calls; test windows reported inconsistently across sources (Jan–Mar 2024 vs Jun–Nov 2024). Treat as a demo, not evidence. — [TradingAgents arXiv](https://arxiv.org/abs/2412.20138v1); [project page](https://tradingagents-ai.github.io)
- FinMem (arXiv 2311.13743, AAAI-SS 2024 / IEEE TBD): layered memory + character design; reports Sharpe > 2.0 and cumulative return > 0.35 on TSLA/NFLX with daily data, best TSLA result under a "self-adaptive risk" setting that turns conservative when short-term cumulative return is negative; trained on < 6 months of daily data. Small sample of single stocks, daily horizon. — [FinMem](https://arxiv.org/abs/2311.13743)

**Price/technical-analysis specific**
- Georgia Tech thesis "AI Trading: Evaluating LLMs for Technical Market Analysis" (arXiv 2607.15414, 2026): GPT-4 Turbo, Claude 3 Opus, Gemini 1.5 Pro, Llama 3 70B, FinGPT; tasks = candlestick pattern recognition from 5-candle OHLC, BUY/SELL/HOLD from 30 days OHLC + RSI/MACD/Bollinger; 50 S&P 500 stocks, 2023 data, temperature 0. GPT-4 Turbo signal accuracy "exceeded 60% in trending markets but fell to nearly 51% in sideways markets." Long-only backtest, 0.10% round-trip cost: GPT-4 Turbo 31.2% annualized, Sharpe 1.42; FinGPT Sharpe 1.31; S&P buy-and-hold 20.3%, Sharpe 0.88; Llama 3 70B MDD −18.9%. **Daily decisions only; no mechanical-rule baseline (no SMA/RSI comparison); single year (2023 bull market).** — [alphaxiv 2607.15414](https://www.alphaxiv.org/abs/2607.15414)
- Same thesis: in sideways markets models "see patterns or signals where none exist"; numerical hallucination in 8.3% (Claude 3 Opus) to 22.7% (Llama 3 70B) of incorrect FinanceBench answers. — [alphaxiv 2607.15414](https://www.alphaxiv.org/abs/2607.15414)
- "Is GPT4 a Good Trader?" (arXiv 2309.10982): daily K-line data (Shanghai index), Elliott-wave prompts, evaluated manually by "interpretative depth"; no accuracy numbers, no backtest. — [arXiv 2309.10982](https://arxiv.org/abs/2309.10982)
- Chen (IJACSA Vol.16 No.4, 2025, peer-reviewed journal): vision-instruct LLMs reading candlestick images vs vision deep learning vs numeric models; abstract-level finding: prompt-based chart-reading LLMs are "limited by biases in prediction confidence" and applying LLMs to chart images is harder than numeric inputs. (I could not extract the numbers from the PDF.) — [IJACSA paper PDF](https://www.thesai.org/Downloads/Volume16No4/Paper_2-Comparing_Vision_Instruct_LLMs_Vision_Based_Deep_Learning.pdf)
- QuantAgent (arXiv 2509.09995, "Price-Driven Multi-Agent LLMs for High-Frequency Trading"): four agents (Indicator, Pattern, Trend, Risk), zero-shot on 10 instruments incl. BTC and Nasdaq futures at **4-hour** intervals; claims to beat "random prediction baselines" (one version of abstract) or "strong neural and rule-based baselines" (another version) — the two abstracts disagree, no numbers on the abstract page. Not minute-level despite the "HFT" title. — [QuantAgent](https://arxiv.org/abs/2509.09995v2)
- "What Does ChatGPT Make of Historical Stock Returns?" (Chen, Green, Gulen, Zhou, arXiv 2409.11540): given return histories, LLM forecasts "over-extrapolate, placing excessive weight on recent performance" (the opposite of the actual short-term reversal in stock returns), are optimistic relative to realized returns, but 80% intervals are better calibrated than human surveys. — [arXiv 2409.11540](https://www.arxiv.org/abs/2409.11540)
- Minute-level crypto nowcasting (FinTech journal, DOI 10.3390/fintech4040053, 2025, peer-reviewed): GPT-4.1, Gemini-2.5-Pro, Claude-3-Opus, DeepSeek-Reasoner, Grok-4 on minute data for 12 cryptos vs GARCH/HAR-RV/GRU/LSTM. Reported avg accuracy gain 9.47% over econometric and 4.63% over neural baselines, led mostly by stablecoins; LLMs struggled on BTC/ETH "abrupt intraday spikes" and under market stress. Secondary news summary; metric not defined; nowcasting of "conditions", not direction trading. — [devdiscourse summary](https://www.devdiscourse.com/article/technology/3645936-llms-outperform-traditional-models-in-real-time-cryptocurrency-forecasting)
- Zero-shot time-series foundation models (Chronos, TimesFM, Moirai — not LLMs) on high-frequency data (Wołyniak & Ślepaczuk, U. Warsaw): large gross returns come from very frequent trading and mostly vanish with realistic transaction costs; robust HF performance "probably needs sparser signals". — [WNE UW seminar](https://www.wne.uw.edu.pl/badania-i-nauka/konferencje-i-seminaria/nadchodzace-wydarzenia/seminarium-z-udzialem-jana-wolyniaka-studenta-wne-uw)

**News-sentiment line (where the edge is real, daily horizon)**
- Lopez-Lira & Tang, "Can ChatGPT Forecast Stock Price Movements?" (arXiv 2304.07619, v6 Oct 2025, forthcoming journal): GPT-4 headline scores reach ~90% portfolio-day hit rates on the non-tradable initial reaction and significantly predict subsequent drift, strongest for small stocks and negative news; long-short on GPT-4 gives the highest Sharpe; GPT-1/2/BERT cannot forecast; **returns decline as LLM adoption rises**. Per-prompt accuracy is only ~51% (Lopez-Lira to Fortune); the signal works by aggregating across many firms and days. — [arXiv 2304.07619](https://arxiv.org/abs/2304.07619); [Fortune interview](https://dc.fortune.com/2023/04/21/chat-gpt-market-predicting-stock-price-movements)
- Anic, Barbon, Seiz, Zarattini, "ChatGPT in Systematic Investing" (arXiv 2510.26228): LLM-enhanced momentum portfolio Sharpe 0.57 → 0.69 full sample, 0.79 → 1.06 out of sample, with higher turnover (search snippet; I could not read the PDF body). — [arXiv 2510.26228](https://arxiv.org/pdf/2510.26228v1)
- Yerra & Allam (arXiv 2605.06730): LLM scores news on four 1–5 axes for 30 NASDAQ-100 stocks, OOS 2019–2023. Sharpe with vs without LLM: ridge 0.653 → 0.614 (naive append hurts) / 0.674 (tilt); top-10 portfolio 1.032 (B&H) → 1.067; RL 0.907 → 0.920. Advantage disappears at ≥0.2% costs (Sharpe 0.899 < B&H 1.032); simpler signals (PC1 1.256, FinBERT 1.206) beat the LLM axes. — [arXiv 2605.06730](https://arxiv.org/html/2605.06730)
- "When Valid Signals Fail: Regime Boundaries Between LLM Features and RL Trading Policies" (2026): LLM-only agent had the worst Sharpe (−0.411) because trading on idiosyncratic news during systemic shocks adds noise; adding macro features made the LLM signals usable (search snippet via review site). — [themoonlight review](https://www.themoonlight.io/review/when-valid-signals-fail-regime-boundaries-between-llm-features-and-rl-trading-policies)

### Inferences
- Every rigorous result that shows LLM edge comes from **text** (news, filings) at **daily** horizon; studies feeding LLMs only price/indicators either show marginal accuracy (51–60%, regime-dependent) or are not benchmarked against mechanical rules at all. For a minute-by-minute gold bot fed only OHLC/EMA/ATR, the literature offers no positive evidence and several negative signals (over-extrapolation of recent moves, pattern-seeing in chop, fee drag).
- The AI-Trader hourly result (2/6 models beat QQQ over 5 weeks at 2–3× drawdown) is the best available "intraday-ish" data point and is far too short to distinguish skill from luck; its own authors stress weak risk management and unstable recommendations.
- The strong regime dependence (StockBench: 0/N beat baseline in downturn; GT thesis: 60% trending vs 51% sideways) suggests any LLM value is really a trend-following bias that wins in trends and bleeds in ranges — something a mechanical EMA/ADX rule does cheaper and consistently.

### Gaps
- No study found that evaluates LLMs at 1-minute cadence on FX/gold with OHLC+indicator prompts against a mechanical baseline on identical timestamps.
- Full numeric tables for LiveTradeBench, Agent Market Arena, Chen (IJACSA) and QuantAgent were not accessible from the pages I could fetch.
- Lopez-Lira Sharpe magnitudes and the size of the post-2023 decay are in the PDF, not the abstract.

## KQ2. Open-source LLM trading bots with honest live/paper results, and their architecture

### Takeaway
The only live, real-money, multi-model public test (nof1 Alpha Arena, Oct–Nov 2025, 3-minute cadence) had 4 of 6 LLMs lose 30–63% of capital in ~3 weeks, win rates of 25–30%, fee drag of >10% of capital, and an independent analysis found results indistinguishable from a random strategy; GitHub bots that publish logs mostly use "LLM decides, code enforces hard risk rules", and none publish audited out-of-sample P/L that beats a passive benchmark.

### Cited Findings
- nof1 Alpha Arena season 1 [live contest, real money]: six LLMs, $10,000 each, Hyperliquid perps, Oct 17–Nov 3 2025. Final: ChatGPT (GPT-5) −$6,267 (−63%), Gemini −$5,671, Grok −$4,531, Claude Sonnet −$3,081, DeepSeek +$489, Qwen3 Max +$2,232. Gemini made 238 trades vs Claude 38. **All six had win rates between 25% and 30%.** Fees: Qwen $1,654, Gemini $1,331. On Oct 27 DeepSeek and Qwen had roughly doubled before giving it back. nof1: trading costs dominated P&L because agents over-traded and took small gains that fees erased; "LLMs don't really handle numerical time series data very well"; models were constrained in asset universe and action space; harness context window was limited. — [Protos](https://protos.com/llm-crypto-trading-contest-finds-llms-cant-trade-crypto); [Forklog](https://forklog.com/en/four-out-of-six-ai-models-suffer-losses-in-trading-tournament/)
- Independent statistical critique of Alpha Arena (Magnus Ross, "Zero alpha") [practitioner analysis]: simulated a random strategy on the same six assets with similar leverage and 3-minute frequency; a P&L as good as the best model was expected in ~10% of random runs; after the market turned, random sample paths looked like the LLM paths; conclusion "little evidence that any LLM trades skillfully", distinct "personalities" may be token bias; possible bottleneck is the setup (lagged indicators in the prompt). — [magnusross.github.io](https://magnusross.github.io/posts/nof1-analysis)
- Alpha Arena season 1.5 (Nov 19–Dec 3 2025): "Mystery model" (Grok 4.20) won, ~+12% in two weeks; GPT-5.1 2nd, Gemini 3 3rd; nof1 said the next season would use "better prompts and statistical rigor", web search, longer reasoning, multi-step execution. nof1 founder Jay Azhang: "Giving an LLM money right now and just having it go — that's not a thing yet." — [Forklog](https://forklog.com/en/ai-model-grok-4-2-triumphs-in-trading-tournament/); [KuCoin news](https://www.kucoin.com/news/flash/ai-trading-models-struggle-in-live-market-tests-majority-of-systems-report-losses)
- Alpha Arena stock round (reported by ThinkAdvisor, May 2026): eight systems incl. Claude, Gemini, ChatGPT each managed $10,000 in U.S. tech stocks; of 32 trading results only 6 showed gains; aggregate portfolio down ~33%. (Secondary report; season not clearly identified.) — [ThinkAdvisor](https://www.thinkadvisor.com/amp/2026/05/06/why-ai-bots-arent-ready-to-replace-your-fund-manager/)
- kojott/LLM-trader-test [GitHub, anecdote]: DeepSeek via OpenRouter, Binance data, **15-minute loop** with three timeframes (15m execution: RSI14, MACD; 1h structure: swing highs/lows, S/R; 4h trend: EMAs, ATR for stops). Prompt gets 200×15m, 100×1h, 100×4h candles with EMA20/50/200, RSI, MACD, ATR, volume, plus portfolio snapshot. Output: JSON per coin with signal, side, quantity, profit_target, stop_loss, leverage, confidence (0–1), risk_usd, invalidation_condition, justification. Author explicitly **replaced a 3-minute-bar system**: removed "short-timeframe noise and subjective 'weak momentum' exits", added mechanical exit rules (close only on SL/TP, 1h structure break, or 4h trend reversal; don't close manually within 20% of stop distance). No results published in README; a "+17%" figure is tied to paid prompts and unverified. — [GitHub kojott](https://github.com/kojott/LLM-trader-test)
- LuckyOne7777 "ChatGPT Micro-Cap Experiment" / LLM-Trading-Lab [GitHub, real money $100]: LLM picks trades under hard constraints; automated stop-losses in code; daily CSV accounting; benchmarks vs S&P 500 and Russell 2000; full trade/decision logs; README does not show return numbers (they are in a linked 40-page write-up). — [GitHub LLM-Trading-Lab](https://github.com/LuckyOne7777/LLM-Trading-Lab)
- ulab-uiuc/live-trade-bench: research code behind LiveTradeBench; runs GPT/Claude agents live on US equities and Polymarket; most rigorous open repo found. — [GitHub](https://github.com/ulab-uiuc/live-trade-bench)
- AI-Trader code and evaluation data are open (HKUDS/AI-Trader); architecture = ReAct agent with Check Price / Search / News / Math / Trade tools, minimal prompt context, must act via tool calls. — [AI-Trader](https://arxiv.org/abs/2512.10971)
- DEV Community "reviewer stage" post [anecdote]: LLM reviewer can accept/modify/veto mechanical signals; paper run: ~60% accept, 25% modify, 15% veto; author: "We don't claim this is a better trading strategy." — [dev.to](https://dev.to/a3e_ecosystem/replacing-strategy-gates-with-intelligence-amplifiers-a-reviewer-stage-for-llm-driven-trading-3l0m)
- QuantPedia experiment [practitioner]: ChatGPT "made extremely naive mistakes while still presenting its ideas as the best strategy ever." — [QuantPedia](https://quantpedia.com/can-we-finally-use-chatgpt-as-a-quantitative-analyst/)
- Rogue Quant GPT-5 strategy test [anecdote]: backtest net profit $29,430, PF 1.55, win rate 64.8%, 54 trades — missed the author's PF>3 target. — [Substack](https://roguequant.substack.com/p/i-asked-chatgpt-5-to-build-a-trading)

### Inferences
- The architecture that survives in every credible repo is the same: code computes indicators and owns risk (stops, sizing, max positions), the LLM returns a structured JSON decision, and exits are mechanical. The one hobbyist who ran a 3-minute LLM loop abandoned it for 15-minute decisions with mechanical exits — consistent with nof1's finding that fees from over-trading dominated P&L at 3-minute cadence.
- 25–30% win rates across all six Alpha Arena models with ~3-minute cadence strongly resemble a noise trader paying spread; this is the closest public analogue to a 1-minute Claude loop.

### Gaps
- No open-source repo publishes an audited, out-of-sample, fee-inclusive equity curve where the LLM beats a mechanical baseline on the same timestamps.
- The ChatGPT Micro-Cap experiment's actual return numbers are in a linked paper I did not fetch.

## KQ3. LLM confidence calibration in trading-like decisions

### Takeaway
There is no published evidence that a self-reported "confidence 0.8" from an LLM on a trade correlates with the trade's outcome; the finance-specific calibration work that exists says LLMs over-extrapolate recent returns, are optimistic, have systematic confidence biases on chart inputs, and that confidence scores only become useful when (a) used ordinally as a rank-based gate and (b) the sizing map is re-fitted jointly with the controller that consumes it.

### Cited Findings
- Singh & Rezaeimanesh, "Ordinal Gates, Cardinal Bets" (arXiv 2609.00187): nine open-weight LLMs, confidence maps fit on 2021 FactSet news for Nasdaq-100, OOS 2022–23. A coverage-matched **rank-based gate** depends only on score ordering (monotone recalibration can't change it); **position sizing** uses magnitude so a scale fit to one confidence map is invalid for another. Transferring a scale to a different map reduced certainty-equivalent return in 8/9 models; matching each map to its own fitted scale improved ensemble CER by +9.2 pp/yr (p<0.001), +5.5 pp/yr excluding the biggest contributor, only +1.6 pp/yr under an adaptive-volatility controller. Recommendation: evaluate confidence transformations together with the downstream controller. — [arXiv 2609.00187](https://arxiv.org/abs/2609.00187)
- Chen, Green, Gulen & Zhou (arXiv 2409.11540): LLM point forecasts of returns are optimistic and over-extrapolate; 80% intervals are better calibrated than human surveys but "pessimistic about outliers", giving skewed distributions. — [arXiv 2409.11540](https://www.arxiv.org/abs/2409.11540)
- Chen (IJACSA 2025): chart-reading LLMs "limited by biases in prediction confidence". — [IJACSA PDF](https://www.thesai.org/Downloads/Volume16No4/Paper_2-Comparing_Vision_Instruct_LLMs_Vision_Based_Deep_Learning.pdf)
- FinBench (Ghosh & Devarakonda, arXiv 2607.16229): benchmark for calibration in agentic financial forecasting — models give P(positive return) and an 80% interval scored by Brier and Winkler interval scores; only a pilot (1 trading day, 3 tickers, 33 forecasts), so no usable calibration numbers yet. — [RePEc listing](https://econpapers.repec.org/RePEc:arx:papers:2607.16229)
- Chhikara, "Mind the Confidence Gap" (arXiv 2502.11028): general-QA study of LLM overconfidence; flags financial decisions as a high-stakes case where overconfident wrong outputs are especially harmful. — [arXiv 2502.11028](https://arxiv.org/html/2502.11028v3)
- Lopez-Lira: individual prompt accuracy ~51%; usable only in aggregate across many names/days. — [Fortune](https://dc.fortune.com/2023/04/21/chat-gpt-market-predicting-stock-price-movements)
- Reddit anecdote [unverified]: ECE between 0.078 and 0.297 for Gemini 2.5 Pro on 30 stock targets. — [Reddit snapshot](https://reddit.sentinel-team.org/posts/1s9qfgo/snapshots/2026-04-03T17%3A09%3A23.105682Z)
- Practitioner design pattern (not validated): composite confidence from several signals with position size set by pre-defined confidence thresholds plus portfolio state. — [markaicode](https://www.markaicode.com/ai-quant-trading-bot-backtest-risk-live-execution/)
- Practitioner pitfall: a confidence value that read zero in the strategy tester but non-zero live made backtests non-reproducible; a DB-driven output is "a filter-ranking win rate, not a per-trade win probability". — [mql5 forge Warrior_EA](https://forge.mql5.io/koros0111/Warrior_EA/src/branch/main/Money)

### Inferences
- The defensible use of a Claude "confidence" field is **ordinal**: log it, compute realized win rate / expectancy per confidence bucket on your own closed trades, and only then set a threshold (e.g., trade only in the top tercile of the bot's own historical confidence distribution). Using the raw number for lot sizing without fitting it to your own outcomes is exactly the "transfer a scale to an unfitted map" error that hurt 8/9 models in Singh & Rezaeimanesh.
- With ~51% per-call accuracy at daily horizon on text, per-call confidence at 1-minute horizon on price bars is unlikely to carry information above noise; calibration needs hundreds of closed trades per bucket to measure.

### Gaps
- No paper reports a correlation coefficient between verbalized LLM confidence and realized trade P&L at any horizon.
- Whether confidence from logprobs/self-consistency sampling is better calibrated than verbalized confidence in trading tasks is not studied in finance (only in general QA).

## KQ4. Documented failure modes

### Takeaway
Documented failures are: overtrading that lets fees eat P&L (nof1), trend-chasing/over-extrapolating recent moves (Chen et al.; AI-Trader's Claude 6 trades/period), "hold-to-die" passivity and rigid weights ignoring liquidity (AI-Trader), seeing patterns in sideways markets (GT thesis), late reversals/inconsistent decisions across reasoning stages and sensitivity to how inputs are phrased (TrustTrade, TRIBE), schema/arithmetic errors in JSON outputs (StockBench), numerical hallucination (GT thesis), acting on unverified news (AI-Trader), and large run-to-run dispersion that makes short backtests meaningless.

### Cited Findings
- Overtrading / fees: nof1 — agents over-traded and took small gains that fees erased; Gemini 238 trades in ~17 days; Qwen paid $1,654 in fees on $10k. — [Protos](https://protos.com/llm-crypto-trading-contest-finds-llms-cant-trade-crypto)
- Trend chasing: AI-Trader — Claude-3.7-Sonnet averaged 6.0 trades per period in U.S. hourly and 5.0 in crypto, the highest; attributed to trend-following; Gemini-2.5-Flash positions "surged to 30 before liquidation" in A-shares. — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- Passivity / ignoring risk: AI-Trader — Gemini followed a "passive 'hold-to-die' trajectory" during the Nov crypto correction (−18.63%); GPT-5 "rigidly adhered to target weights without liquidity awareness" (−16.41%). — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- Unverified information: AI-Trader — DeepSeek acted on a "structural slow bull" news item without cross-verification and lagged the index; the system "lacks a systematic information verification module". — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- Instability: AI-Trader — most agents' "generated trading recommendations lack stability" (no quantitative measure given). — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- Recency bias / over-extrapolation: Chen, Green, Gulen & Zhou — LLMs over-extrapolate recent performance like humans, opposite to short-term reversal. — [arXiv 2409.11540](https://www.arxiv.org/abs/2409.11540)
- Pattern-seeing in chop: GT thesis — accuracy ~51% in sideways markets; models "see patterns or signals where none exist". — [alphaxiv 2607.15414](https://www.alphaxiv.org/abs/2607.15414)
- Format/arithmetic errors: StockBench — two error classes, arithmetic (share counts) and schema (breaking JSON); thinking models make fewer arithmetic but more schema errors. — [StockBench HTML](https://arxiv.org/html/2510.02209v1)
- Inconsistency across reasoning stages and input phrasing: TrustTrade (arXiv 2603.22567) — LLM traders "often reverse late" relative to intermediate stage decisions; different agents on the same market reach different trades producing wide swings in return/drawdown; reasoning is stochastic and sensitive to how information is phrased; root cause called "uniform trust" (treating every retrieved input as equally reliable). — [TrustTrade HTML](https://arxiv.org/html/2603.22567v1)
- Prompt sensitivity: TRIBE (AAMAS 2025) — a slight aversion-related phrase in the prompt can stop trading almost entirely. — [AAMAS 2025 p2777](https://aamas.csc.liv.ac.uk/Proceedings/aamas2025/pdfs/p2777.pdf); simulation study 2504.10789 — LLM trading behavior "highly sensitive to the specific instructions in the prompt". — [alphaxiv 2504.10789](https://alphaxiv.org/overview/2504.10789v1); 2604.18373 — targeted prompt interventions shift bubble magnitudes in simulated markets. — [arXiv 2604.18373](https://arxiv.org/html/2604.18373v1)
- Persona drift: "Behavioral Consistency Validation for LLM Agents" (arXiv 2602.07023) studies when LLM trader personas switch trading styles mid-simulation. — [arXiv 2602.07023](https://arxiv.org/html/2602.07023v1)
- Model "personalities"/biases: nof1 — all models showed "consistent biases"; Grok, ChatGPT, Gemini shorted more, Claude "rarely" shorted. Ross: the personalities may be token bias. — [Protos](https://protos.com/llm-crypto-trading-contest-finds-llms-cant-trade-crypto); [Ross](https://magnusross.github.io/posts/nof1-analysis)
- Contradicting own plan: commentary that Season 1 models sometimes contradicted their own prior plans. — [besthub](https://www.besthub.dev/articles/can-llms-trade-crypto-profitably-inside-the-alpha-arena-competition-ace3b75ceaa5)
- Overconfident presentation of naive ideas: QuantPedia. — [QuantPedia](https://quantpedia.com/can-we-finally-use-chatgpt-as-a-quantitative-analyst/)
- Cost of evaluation: TradingAgents could only backtest ~3 months because each decision needs many LLM/tool calls. — [TradingAgents](https://arxiv.org/abs/2412.20138v1)
- Regime failure: no LLM beat passive in StockBench's downturn window; LLM-only RL agent Sharpe −0.411 during systemic shocks. — [StockBench](https://arxiv.org/html/2510.02209v1); [themoonlight](https://www.themoonlight.io/review/when-valid-signals-fail-regime-boundaries-between-llm-features-and-rl-trading-policies)

### Inferences
- The user's memory notes (young losing closes refused in code; trail captures little of peak) match the documented pattern: LLMs reverse decisions late and over-react to the most recent bars, so the fix in the literature and repos is the same — mechanical exits and a hard ban on re-deciding within N bars of entry.
- Nothing in the literature addresses "hallucinated S/R levels" directly, but the GT thesis's 8–23% numerical hallucination rate on financial documents argues for computing all levels in code and never asking the model to derive numbers.

### Gaps
- No study quantifies same-input/different-call decision flip rate (temperature nondeterminism) in a trading task; TrustTrade measures stage-to-final convergence, not call-to-call.
- No study isolates "chasing" (entering after an extended move) as a measured failure with numbers.

## KQ5. Practical recommendations: prompt/context design, consistency, and evaluating added value

### Takeaway
Credible projects converge on: compute everything numeric in code (indicators, levels, regime labels, HTF trend, volatility, the bot's own stats), give the LLM a short structured snapshot, demand a strict JSON decision with a stated invalidation condition, use the model as a gate/veto or ranker rather than the sole signal source, aggregate several samples or sources (consensus) before acting, run it in shadow mode first, and evaluate it only by A/B against a mechanical baseline on identical timestamps with full costs — because the published evidence says the LLM's incremental Sharpe is small (≈0–0.1) and often negative once costs ≥0.1–0.2% per trade are applied.

### Cited Findings
**What to hand to the model**
- StockBench inputs that produced the best results: opening prices, the agent's own last-7-day actions on held stocks, ≤5 news items from past 48h, and fundamentals; removing news dropped Kimi-K2 from 1.9% to 1.4%, removing fundamentals too → 0.6%; 32k-token context cap. — [StockBench](https://arxiv.org/html/2510.02209v1)
- AI-Trader gave "minimal information" (time, positions, cash, prices) and tools; authors identify the lack of a verification module as a weakness and credit the search tool for the one good defensive move (cut tech 99%→70%, 17.3% cash before the Oct 10 −3% Nasdaq day). — [AI-Trader HTML](https://arxiv.org/html/2512.10971v1)
- Regime label matters: "When Valid Signals Fail" — adding macro/regime features turned a Sharpe −0.411 LLM-only agent into a usable one. — [themoonlight](https://www.themoonlight.io/review/when-valid-signals-fail-regime-boundaries-between-llm-features-and-rl-trading-policies)
- Multi-timeframe context with code-computed indicators is the de-facto GitHub pattern (kojott: 15m/1h/4h, EMA20/50/200, RSI, MACD, ATR, S/R, portfolio snapshot). — [GitHub kojott](https://github.com/kojott/LLM-trader-test)
- Ross on nof1: the prompt supplied lagged indicators only; suggests qualitative inputs (news/social) or RL post-training would be needed for any edge. — [Ross](https://magnusross.github.io/posts/nof1-analysis)
- Sparse LLM columns appended naively to a price model hurt (ridge Sharpe 0.653 → 0.614); only a high-conviction tilt helped (0.674); simpler dense signals (PC1, FinBERT) beat the structured LLM axes. — [arXiv 2605.06730](https://arxiv.org/html/2605.06730)

**Decision format**
- StockBench and kojott both require strict JSON; StockBench rejects over-budget trades and forces revision; kojott's JSON includes `invalidation_condition`, `stop_loss`, `profit_target`, `confidence`, `risk_usd`. — [StockBench](https://arxiv.org/html/2510.02209v1); [kojott](https://github.com/kojott/LLM-trader-test)
- FinMem's best result used a self-adaptive risk setting that forces conservatism when short-term cumulative return is negative — i.e., the bot's own recent P&L is fed back as a regime variable. — [FinMem](https://arxiv.org/abs/2311.13743)

**Consistency across calls**
- TrustTrade: parallel independent agents → split reports into atomic claims → hybrid semantic+numeric similarity → consensus groups scored S = α·support + (1−α)·cohesion → down-weight low-support claims. Consensus raised average CR from ~10% to ~26% (MDD ~3% → ~8%); adding memory reduced risk at slightly lower return; caveat: consensus can discard minority-but-correct evidence in fast markets; small stock set and windows. — [TrustTrade](https://arxiv.org/html/2603.22567v1)
- Agent Market Arena: framework/structure (risk style, memory) determined behavior more than backbone — so fixing the harness matters more than picking Claude vs GPT. — [AMA](https://arxiv.org/abs/2510.11695)
- Temperature 0 was used in the GT thesis but repeat-consistency was not measured. — [alphaxiv 2607.15414](https://www.alphaxiv.org/abs/2607.15414)

**LLM as filter vs signal source; ensembles**
- Practitioner "LLM as veto, not originator" [AI-generated blog, anecdotal]: keep signals mechanical, ask the LLM SAFE/VETO before entry; skip entry if the call fails; run in shadow mode logging every veto before enforcing; don't use an LLM for structured data like earnings dates. — [lzwjava veto](https://lzwjava.github.io/llm-as-veto-not-originator-en); [soft spots](https://lzwjava.github.io/three-soft-spots-in-llm-veto-plan-en)
- Reviewer-stage (accept/modify/veto) paper run: 60/25/15% split, no performance claim. — [dev.to](https://dev.to/a3e_ecosystem/replacing-strategy-gates-with-intelligence-amplifiers-a-reviewer-stage-for-llm-driven-trading-3l0m)
- Where LLM-as-signal works in the literature it is a **news** overlay on a mechanical factor (momentum Sharpe 0.79 → 1.06 OOS, Anic et al.; top-10 news tilt 1.032 → 1.067, Yerra & Allam) and the gain reverses at ≥0.2% round-trip costs. — [arXiv 2510.26228](https://arxiv.org/pdf/2510.26228v1); [arXiv 2605.06730](https://arxiv.org/html/2605.06730)
- Lopez-Lira: edge is in aggregation across many decisions, not single calls; it decays as adoption rises. — [arXiv 2304.07619](https://arxiv.org/abs/2304.07619)

**Evaluation**
- Benchmarks that are credible are all live/forward (StockBench Mar–Jun 2025 post-cutoff, AI-Trader live, LiveTradeBench 50 days live, AMA lifelong) precisely because LLM backtests on pre-cutoff data leak. — [StockBench](https://arxiv.org/abs/2510.02209v1); [AI-Trader](https://arxiv.org/abs/2512.10971); [LiveTradeBench](https://www.arxiv.org/abs/2511.03628)
- StockBench ran 3 seeds and averaged; still, per-model differences (0.2–2.5%) are within noise of a −15% drawdown window. — [StockBench](https://arxiv.org/html/2510.02209v1)
- Ross's random-strategy Monte Carlo (same assets, leverage, frequency) is the right null: best LLM equalled a top-10% random path. — [Ross](https://magnusross.github.io/posts/nof1-analysis)
- Confidence gates/sizing must be fit jointly with the controller and checked walk-forward (positive in every fold but smaller than in-sample). — [arXiv 2609.00187](https://arxiv.org/abs/2609.00187)
- Cost sensitivity: time-series FM study — HF gross returns vanish with realistic costs; sparser signals needed. — [WNE UW](https://www.wne.uw.edu.pl/badania-i-nauka/konferencje-i-seminaria/nadchodzace-wydarzenia/seminarium-z-udzialem-jana-wolyniaka-studenta-wne-uw)

### Inferences (applied to a 1-minute gold bot)
- Code should compute and pass: regime label (trend/range from ADX or EMA slope), HTF (H1/H4) trend direction, ATR percentile, distance to code-computed S/R, session (London/NY), spread, news-calendar flag, the bot's own rolling stats (win rate, expectancy, consecutive losses, open-trade age/P&L). The model should **not** be asked to compute levels or indicators (hallucination 8–23% on numbers) and should not see only the last few bars (over-extrapolation).
- Decision cadence: evidence (nof1 3-min → 25–30% win rate and fee death; kojott 3m → 15m) points to deciding at most every 15 minutes or on events (new H1/M15 bar close, level touch), with the 1-minute loop handled by mechanical rules; this also cuts API cost, which per the user's memory must stay below profit.
- Role: use Claude as a veto/ranker on mechanical EMA/ATR setups (output ALLOW/VETO + reason + ordinal confidence), with mechanical SL/TP/trail and a minimum hold before any LLM-initiated exit. Keep a shadow log so every veto can be scored against what the mechanical trade would have done.
- Evaluation: run the mechanical baseline and the LLM-gated variant on identical timestamps for ≥ several hundred trades with real spread/commission, compare expectancy and drawdown, and compute a random-veto null (veto the same fraction of trades at random) before crediting the LLM. Per-model naming matters little (AMA); harness design and cost control matter most.

### Gaps
- No published A/B (same timestamps, same costs) of "mechanical strategy" vs "mechanical + LLM veto" exists; the veto design is practitioner lore.
- No paper reports the cost/benefit of 1-minute LLM calls (API spend vs incremental P&L).
- Calibration of verbalized confidence against trade outcomes at intraday horizon is unmeasured anywhere.
